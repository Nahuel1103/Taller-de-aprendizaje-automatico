## 🛠️ Manual de ejecución

1. **Instalación de Python**  
   Asegúrate de tener **Python** (versión 3.7 o superior) instalado en tu máquina.  
   Si no lo tienes, descárgalo desde [python.org](https://www.python.org/downloads/).

2. Instala todas las dependencias necesarias con el siguiente comando:  

   ```bash
   pip install -r <librerias_que_sean_necesarias>
3. Accede a la carpeta correspondiente según el práctico o material que quieras revisar.
4. Sigue las instrucciones contenidas en cada archivo notebook.
